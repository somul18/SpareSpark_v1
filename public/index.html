ServiceNow plugin

SpareSpark runs on its own. The optional ServiceNow plugin sends robot incidents here and receives stage updates back as work notes, so coordinators can approve parts from either side.

  1. Import servicenow-plugin/dist/sparespark-servicenow-update-set.xml into your instance (System Update Sets > Retrieved Update Sets > Import Update Set from XML), then preview and commit.
  2. Set the system properties sparespark.base_url, sparespark.api_key and sparespark.inbound_token.
  3. Point SpareSpark's SPARESPARK_WEBHOOK_URL at the instance's SpareSpark Scripted REST API /events resource (the full path is shown on the API record).
